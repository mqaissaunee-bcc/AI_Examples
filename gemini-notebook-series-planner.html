Video Series Planner for Gemini Notebook

Give it the same source you load into Gemini Notebook (formerly NotebookLM). It splits the material into a sequence of videos and writes one Video Overview prompt for each, so the whole series covers everything without repeating itself.

1Add your source

Use the same material that's in your notebook. Headings in the source become the building blocks of the series.

PDF headings are found by font size. The PDF reader loads from cdnjs the first time you use it.

Pages on the same site as this tool load directly. Most other sites block this; if yours does, open the page, select all, copy, and use Paste text.

    4Run the prompts

    Generate one video at a time in the same notebook.

    1. In Gemini Notebook, open the notebook that holds this source and make sure every source is selected.
    2. In the Studio panel, select the pencil icon on Video Overview.
    3. Choose the format and visual style shown on the card, paste the prompt, and generate. Videos generate in the background, so you can start the next one while the last one finishes.
    4. Check off each video here as you go. Your progress stays in this browser.
