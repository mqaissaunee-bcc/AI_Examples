How it works5-minute read. Nothing to do yet.

Your chatbot has three parts. A small script on each of your pages draws the chat button and window. A Cloudflare Worker is a tiny program that lives on Cloudflare’s servers, free; it acts as a middleman. Gemini is Google’s AI model, which writes the answers.

Why the middleman? Talking to Gemini requires a secret API key, which works like a password tied to your Google account. Anything on a public web page can be read by anyone, so the key can never go in your pages. The Worker keeps the key locked away, adds your instructions, and passes along only the question and the answer.

Grounding is what makes it a course assistant rather than a general chatbot. Every question carries the text of the page the student is on, so “what does this command do?” gets an answer about this module. In Step 8 you can also give it your own documents: a syllabus, notes, FAQs, handouts.

Read this before you share it with students.

On Gemini’s free tier, Google’s terms have allowed submitted prompts to be used to improve its products. The paid tier does not do this. Check Google’s current terms before you launch. Either way, tell students not to type personal information into the assistant. The button you’ll install shows a short reminder under the chat box.

Check your college’s policies on AI tools and on third-party services that process student input. Some institutions require a review.

Will this work inside Canvas, Blackboard or Moodle?

Not directly: learning management systems strip scripts from pages you write in their editors. Host the page yourself, then link to it or embed it from the LMS. The button works inside an embedded page.

Get a Gemini API key3 minutes

  1. Go to Google AI Studio’s API key page and sign in with your Google account. Accept the terms if asked.
  2. Select Create API key. If it asks for a project, choose the default or let it create one.
  3. Copy the key. It’s a long string of letters and numbers. Keep this tab open; you’ll paste the key into Cloudflare in Step 5.

Treat the key like a password. Never put it in a web page, a shared document or an email. If it leaks, delete it in AI Studio and create a new one. Screens in AI Studio and Cloudflare change from time to time; if a button name differs slightly, look for the closest match.

Add your own resourcesOptional. 20–40 minutes depending on the path.

So far the assistant knows the page a student is reading. To have it also draw on a syllabus, lecture notes, FAQs or handouts, pick one of three paths. They differ in how much material they handle and where your files are kept.

The two larger paths use retrieval-augmented generation (RAG). Your files are split into short passages and indexed. When a student asks something, the system finds the few passages that best match the question and hands only those to Gemini. A knowledge pack instead sends all of your material with every question. That is simpler, but it only suits a modest amount of text.

    Keep it safe and running5-minute read

    The Worker you pasted already has these protections built in:

    • Only your site can use it. Requests from other web addresses are refused, so nobody can borrow your assistant from their own pages.
    • A per-student speed limit. Each visitor gets 10 questions per minute. The limit is approximate, but it stops runaway use. Students who hit it see a “busy, try again in a minute” message.
    • Size caps. Long pastes and long conversations are trimmed before they reach Gemini.
    • No key in the browser. The key exists only as a Cloudflare secret.

    Watching usage

    Cloudflare shows request counts and errors on your Worker’s Metrics tab, and live error messages under Logs. Google AI Studio shows how much of your Gemini allowance you’ve used. If you move to Gemini’s paid tier, set a budget alert in Google Cloud Billing so a busy week can’t surprise you.

    When Google renames models

    Google releases new Gemini models often and eventually retires old names. The default gemini-flash-latest is an alias that follows Google’s current fast model, so it rarely needs changing. If the assistant suddenly stops answering and the Worker logs show a “not found” error for the model, open Google’s models page. Copy a current model name into the MODEL variable in Cloudflare, then deploy.

    Turning it off

    To pause the assistant, delete the GEMINI_API_KEY secret, or delete the Worker. The button stays on your pages and shows a “couldn’t reach the assistant” message. To remove it completely, delete the <script> line from your pages.

    Fix common problems

    Most problems show up in two places: the Worker’s Logs tab in Cloudflare, and the browser’s console on your course page. To open the console, press F12 (on a Mac, ⌥ Option+⌘+J) and select Console.

    The chat button doesn’t appear

    Check that assistant.js is in the same folder as the page, or that the path has the right number of ../. Open https://your-site/assistant.js in a tab: you should see code, not a 404 page.

    Check that the <script> line is above </body>, not inside a comment, and that GitHub Pages has finished updating.

    “Sorry, I couldn’t reach the assistant”

    Usually the Worker doesn’t recognize your site. The ALLOWED_ORIGINS variable must be just the scheme and host, such as https://yourname.github.io. It has no folder and no trailing slash. Fix it in Cloudflare and deploy.

    Also check that the Worker address in assistant.js matches the one Cloudflare shows. If you change it, download the file again from Step 7.

    Step 6 says the key wasn’t found

    The secret must be named exactly GEMINI_API_KEY and its type must be Secret. After adding it, select Deploy.

    The assistant answers, but ignores the page

    Your pages may not use a <main> element. In Advanced settings, change “Part of the page to read” to body, or to the selector that wraps your content, then download assistant.js again.

    “The assistant is busy right now”

    Either one student hit the per-minute limit, or your Gemini free-tier allowance ran out for now. AI Studio shows which. Free-tier limits reset over time. For a large class, consider the paid tier.

    The logs show a Gemini error 400 or 404

    A 404 that mentions the model means the model name has been retired. See “When Google renames models” in Step 9. A 400 that mentions a tool or file search means the model doesn’t support that feature yet; use a model listed on the File Search page.

    A 400 or 403 that mentions the API key means the key is wrong or was deleted. Create a new key and replace the secret.

    AI Search (path C) returns nothing

    Check that indexing has finished, that the AI binding exists, and that AI_SEARCH_NAME matches the instance name exactly. If the search fails, the Worker logs a message and keeps answering from the page alone, so the chat never breaks.
